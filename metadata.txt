about=Media Hub 1.4.0 is a light, native-looking multimedia dock for QGIS 3.44 (Qt5) on Windows by JulienH77. Watch video files from a remembered folder or direct URLs using optional system VLC; choose audio and subtitle tracks (including external SRT), adjust playback speed and volume, and use Picture-in-Picture with editable keyboard shortcuts. Browse the Web using optional Qt WebEngine or open sites in the external browser. Listen to 15 preconfigured French radio stations, including RTL, Franceinfo, France Inter, FIP, Europe 1 and NRJ, with compact clickable tiles and the ability to add your own streams. Keep local notes. Requires VLC 64-bit for reliable video/radio; Qt WebEngine may need an OSGeo4W install. Radio availability depends on servers and network restrictions. Experimental; no analytics, no bundled codecs. MIT licensed.

changelog=1.4.0 - Consolidated feature update since 1.3.2 (QGIS 3.44):
    RADIO: Add Franceinfo (user-provided high-quality AAC URL), Europe 1, NRJ, Nostalgie, Chérie FM, RTL2, France Culture, France Musique, RFM, Skyrock and Fun Radio, for 15 built-in stations. Add compact, square, clickable radio tiles and text tiles for custom stations. Add alternative streams where available.
    VIDEO: Add folder-based video library with saved folder, dropdown playback, refresh and automatic folder detection. Add VLC audio/subtitle track selection and external SRT/ASS/VTT subtitles. Improve PiP layout, centered playback controls, legible +/-10 s buttons, independent volume (0 to 200 percent with VLC) and playback-speed control; enlarge primary play/pause button.
    KEYBOARD: Add Space, arrow keys and Q/S/D video controls; new Settings dialog to customize/reset shortcuts, enable/disable shortcuts and edit preferences. Keys apply within Video or PiP, not globally in QGIS.
    WEB: Add external-browser fallback when Qt WebEngine is unavailable; retain YouTube and QGIS shortcuts.
    GENERAL: Refine light QGIS-native panel, preserve persisted notes and settings, update English/French documentation, author attribution and MIT license. Experimental: streaming depends on network and optional components.
    1.3.2 - Replace subprocess with Qt QProcess; adjust Qt enumerations and plugin metadata.
