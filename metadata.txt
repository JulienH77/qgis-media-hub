about=Media Hub is a lightweight dock panel for QGIS 3.44 (Qt5) on Windows. It combines a local video player (pause, 10-second skip, variable speed, picture-in-picture and full screen), an optional Chromium-based web tab with a YouTube shortcut, live Internet radio including RTL, and persistent notes. Developed by JulienH77. VLC Media Player 64-bit is recommended for video and radio; Qt Multimedia is a limited fallback. The web tab requires PyQtWebEngine (Qt5 / OSGeo4W python3-pyqtwebengine) and is not guaranteed to play every website. Radio streams may be blocked by network policies; the optional QGIS network relay supports redirects and proxy settings, but radio playback has not yet been verified on all networks. Experimental release. No bundled VLC binaries, no telemetry. Source code and support: see the public repository.
